# Upute za HTML

Ako se ne može eksportati doc zbog veličine slika, može se downloadati kao html/zip te je potrebno dodati metapodatke na početku. Npr. dovoljno je samo id: abc.

Zatim se napravi claat export fileName.html

Jedini problem je što se svi heading moraju pomaknuti (h1 postaje h2 itd).
